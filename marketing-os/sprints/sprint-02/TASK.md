# Sprint 02 — Auth

## Goal

Users can register, verify email, login, logout, reset password. Next.js talks to Laravel Sanctum.

## In scope

- Auth API + web forms (functional)
- Email verification + password reset (log/mailhog driver locally)
- Profile basic update (name)
- Sanctum setup for SPA/token

## Out of scope

- Workspaces/RBAC (Sprint 03)
- Social login
